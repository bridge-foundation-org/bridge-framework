# codegen — TypeScript & OpenAPI Generator

Converts a compiled `BridgeFile` AST into a type-safe TypeScript client and an OpenAPI 3.0 specification.

## Overview

The `codegen` crate takes the output of the `compiler` crate and produces ready-to-use artifacts:

| Output | Function |
|--------|----------|
| TypeScript fetch client | `generate_typescript(file)` |
| OpenAPI 3.0 JSON spec | `generate_openapi(file)` |
| Single-service client | `generate_typescript_service(svc)` |

## Quick Start

```rust
use compiler::parse;
use codegen::{generate_typescript, generate_openapi};

let src = r#"
service users
auth bearer
endpoint list   GET  /users
endpoint get    GET  /users/:id
endpoint create POST /users
"#;

let file = parse(src).unwrap();
let ts_client = generate_typescript(&file);
let openapi    = generate_openapi(&file);
```

## Generated TypeScript

The TypeScript output is a self-contained module with zero runtime dependencies (only native `fetch`).

### Structure

For a file with services `users` and `posts`, the output contains:

```
BridgeError         — typed error class
request()           — raw fetch helper (internal)
requestJson<T>()    — typed JSON helper (internal)

createUsersClient() — per-service factory
  .list()
  .get(id)
  .create(body?)

createPostsClient() — per-service factory
  .list(userId)
  .create(body?)

createClient()      — root factory (returns all services)
```

### Example Output (abridged)

```typescript
// Auto-generated by bridge-codegen — do not edit manually.

export class BridgeError extends Error {
  constructor(
    public readonly code: number,
    message: string,
    public readonly body?: string,
  ) { ... }
}

export function createUsersClient(baseUrl: string, token: string) {
  const h = () => ({ Authorization: `Bearer ${token}` });
  return {
    async list() {
      return requestJson(baseUrl, "GET", "/users", undefined, h());
    },
    async get(id: string) {
      return requestJson(baseUrl, "GET", `/users/${id}`, undefined, h());
    },
    async create(body?: unknown) {
      return requestJson(baseUrl, "POST", "/users", body, h());
    },
  };
}

export function createClient(baseUrl: string, token: string) {
  return {
    users: createUsersClient(baseUrl, token),
  };
}
```

### Auth Headers

| Scheme | Generated header |
|--------|-----------------|
| `bearer` | `Authorization: Bearer <token>` |
| `api_key` | `X-Api-Key: <key>` |
| `none` | no auth header |

Auth is applied per-service (inherited by all endpoints) or per-endpoint when overridden.

### Path Parameters

Path params (`/users/:id`) become typed function arguments:

```typescript
// endpoint: GET /users/:id
async get(id: string)   // single param
// endpoint: GET /orgs/:org/repos/:repo
async get(org: string, repo: string)  // multiple params
```

### POST / PUT / PATCH Endpoints

Mutating endpoints accept an optional body:

```typescript
async create(body?: unknown): Promise<unknown>
```

## Generated OpenAPI 3.0

`generate_openapi` returns a JSON string conforming to OpenAPI 3.0.0.

### Conversions

| Bridge DSL | OpenAPI |
|------------|---------|
| `:id` in path | `{id}` parameter |
| `auth bearer` | `bearerAuth` security scheme |
| `auth api_key` | `apiKeyAuth` security scheme |
| POST/PUT/PATCH | `requestBody` with `application/json` |

## API Reference

### `generate_typescript(file: &BridgeFile) → String`

Generates a complete TypeScript module for all services in the file.

### `generate_typescript_service(svc: &Service) → String`

Convenience wrapper — generates a TypeScript module for a single service.

### `generate_openapi(file: &BridgeFile) → String`

Generates an OpenAPI 3.0.0 JSON specification for all services.

## CLI Usage

```bash
# Compile and generate (daemon does this automatically)
bridge compile-file myapp.bridge

# Pipe to file
bridge compile-file myapp.bridge > frontend/bridge.gen/client.ts
```

## Used By

- **daemon/tcp** — handles `Compile` and `CompileFile` commands
- **daemon/http** — POST `/api/v1/compile` endpoint
- **e2e-tests** — compiler → codegen pipeline tests

## Design Notes

- Zero external dependencies — pure `std`.
- Template-based generation: no intermediate IR, just string building.
- OpenAPI path param conversion is handled in codegen (`:id` → `{id}`) so the compiler remains format-agnostic.
- Generated TypeScript uses only native browser APIs (`fetch`, `JSON`) — no bundler or package manager required.
