# Bridge Framework

Bridge is a lightweight Encore-inspired framework for defining services, compiling API contracts, and generating typed frontend clients.

## Quick start

1. Start the daemon: `cargo run -p daemon`
2. Install the CLI: `cargo install --path cli`
3. Run the dev UI: `cd frontend && npm install && npm run dev`
