# @bridgebase/manifest

TypeScript types + builder for the BridgeBase infra manifest
(`bridgebase.lock.json`) — the canonical artifact every deploy target
consumes (ADR-0001).

## Parity contract

The Rust crate `infra-manifest` (in `bridgebase-cli/crates/infra-manifest`)
owns the schema. This package reproduces it exactly, including the SHA-256
`content_hash` computed over the *canonical* serialization (fixed field
order, sorted maps, empty-container elision). The test suite pins parity
byte-for-byte against a golden fixture generated by the Rust crate — if
this package's output ever diverges, CI fails before any deploy target can
be handed a mismatched lock.

## Usage

```ts
import { ManifestBuilder } from "@bridgebase/manifest";

const lock = new ManifestBuilder("demo")
  .language("ts")
  .bucket("media", { public: false })
  .topic("events")
  .database("main")
  .service("api", {
    image: "registry.example/demo-api:1.4.2",
    ports: { 8080: 8080 },
    buckets: ["media"],
    topics: ["events"],
    databases: ["main"],
  })
  .finalize(); // stamps content_hash

await lock.verify(); // throws if contents were mutated after finalize
```

## Test

```sh
npm test   # node:test, zero dependencies
```

Regenerate the golden fixture after intentional schema changes:

```sh
cd ../../bridgebase-cli && cargo run -p infra-manifest --example emit_sample \
  > ../bridge-framework/sdk-ts/test/fixtures/sample.lock.json
```
